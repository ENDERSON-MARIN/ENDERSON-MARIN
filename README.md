Engenheiro de Software Full-Stack com **+10 anos de experiência acumulada em TI** e **+5 anos dedicados exclusivamente ao desenvolvimento de sistemas web em produção**. - 🤖 **Inovação & IA:** Desenvolvimento de automações de workflow e integração de recursos com Inteligência Artificial para otimização de processos corporativos.
